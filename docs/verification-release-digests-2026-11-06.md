# 小版本摘要与失败重试核验

日期：2026-11-06，用户授权收紧版本更新噪声。

## 行为

- 重大版本继续独立解读，重要性仍为版本号/说明关键词启发式，不是人工背书。
- 未发表的小版本按项目、UTC日期和既有失败状态分组，每批最多40条，形成不可变摘要。后续版本形成后续批次，不改写已发表文章或有效处理租约。
- 保留原始事件与正文；原始成员链接映射摘要。原始未成文小版本禁止直接进入生成队列。列表和详情展示UTC日期、成员数量及官方链接，移除旧的无效周合并开关。
- 每个成员作为独立来源提供给模型，正文总预算16000字符，标注节选及保存时截断。源码固定最新成员tag，仅代表该版本。公开列表/详情不发送成员正文，后台保留正文用于生成。
- 摘要继承成员尝试次数、错误类别和最晚退避时间，不能通过合并刷新预算。

## 重试规则

- 最多3次处理尝试，包含首次。每次成功claim增加次数；一次处理可能含生成、一次格式修复和事实审核。
- 临时故障首次退避15分钟、第二次30分钟；校验失败首次1小时、第二次2小时。每3小时生成调度取符合条件的队列，不保证到期立即运行。
- 资料问题立即暂停；第三次失败停止自动重试。修复原因后可用私有管理CLI恢复。公开网站没有管理写接口。
- 20分钟租约保护并发；预检失败不claim、不消耗内容尝试次数。
